Each example is an agent you can have running in minutes: its agent file, what `config.yaml` needs,
the commands to try it, and what it shows of how Wardrik works. Copy one, change its prompt, and it
is yours. Each takes the daemon [installed](/getting-started/install/) and a model provider's key,
as the [Quickstart](/getting-started/quickstart/) gives it one.
